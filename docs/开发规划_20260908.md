# AgentMonitor V3 实现计划（开发规划）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 V2 单文件监控器重构为模块化包（两个探测器 + 统一状态解析），并新增成本/Token 聚合、异常告警、历史回看+搜索、会话管理 4 项能力，输出浅色仪表盘看板 + watchdog 守护。

**Architecture:** 零第三方依赖的 Python 标准库包。`detectors/` 提供统一 `Detector.detect() -> [SessionRef]` 接口（CLI 进程扫描 / 网页版 HTTP 轮询），`parser.py` 是唯一 jsonl→Session 状态解析，`server.py` 只做合并去重与路由。历史/聚合走 SQLite 派生索引（jsonl 仍是唯一事实源）。

**Tech Stack:** Python 3 标准库（`http.server` / `sqlite3` / `subprocess` / `urllib` / `json` / `glob` / `unittest`），前端原生 HTML/JS/CSS（无框架无 CDN），macOS `osascript`（跳转 + 通知）。

## Global Constraints

- 零第三方依赖：Python 仅标准库；前端无框架/CDN。禁止引入 pytest/requests/任何 pip 包。
- 只读安全：不写回、不修改 `~/.pi/agent/sessions/**/*.jsonl` 与 Pi 任何配置。
- `/api/jump`、`/api/kill` 必须做路径/ID 白名单校验（沿用 V2 安全修复，参考 `monitor_server.py`）。
- 所有 API 响应 `Cache-Control: no-store`。
- 端口 8571（与 V2 相同，迁移时先停 V2）。
- 数据源路径：`~/.pi/agent/sessions/`（jsonl），pi-web 地址 `http://127.0.0.1:30141`。
- 视觉：浅色仪表盘风（浅底 + 状态色块 + 数据卡片）。
- 文件命名：所有产出文档带 `_YYYYMMDD` 日期后缀。
- V3 需独立 git 仓库（V2 现状无 git）。

from agentmonitor.parser import parse_session_jsonl, session_id_from_path

def _write_jsonl(lines):
    f = tempfile.NamedTemporaryFile(mode="w", suffix=".jsonl", delete=False)
    for ln in lines:
        f.write(json.dumps(ln) + "\n")
    f.close()
    return f.name

class TestParser(unittest.TestCase):
    def test_session_id_from_path(self):
        self.assertEqual(session_id_from_path("dir/abc_1234567890abcdef.jsonl"), "1234567890abcdef")

    def test_parse_basic_session(self):
        p = _write_jsonl([
            {"type": "session_info", "cwd": "/Users/me/proj", "model": "claude-sonnet-5"},
            {"type": "assistant", "message": {"usage": {"input_tokens": 10, "output_tokens": 5}}},
        ])
        s = parse_session_jsonl(p)
        self.assertEqual(s.model, "claude-sonnet-5")
        self.assertEqual(s.tokens_in, 10); self.assertEqual(s.tokens_out, 5)

if __name__ == "__main__":
    unittest.main()
